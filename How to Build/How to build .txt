===== PWA / static website (Serwist + .\out\) =====

1st — npm install                    (zarurat ho tab)

2nd — npm run build:static           (.\out\ folder banega)

3rd — .\out\ deploy karo HTTPS par (Netlify/Cloudflare/VPS/waghaira) ya local test ke liye project root se: npx serve out  — browser root URL kholo.

      (Prod install / SW stable = HTTPS ya localhost; file:// avoid karo.)

(Optional agar tiers seed chaho build time — PLANS_SEED_URL / PLANS_SEED_FILE set karke dubara step 2.)





===== Android — remote WebView (site HTTPS par deploy; APK sirf shell, kam rebuild) =====

Har web change ke baad sirf pocket-ledger.com deploy karo — APK dubara banane ki zarurat nahi jab tak native plugins na badlo.

1st — .\out\ ko HTTPS deploy (roz wala workflow)

2nd — npm run cap:sync:remote
      (alg URL: npm run cap:sync:remote -- https://staging.pocket-ledger.com)
      Ya PowerShell:
      $env:CAP_USE_REMOTE_WEB = "1"
      $env:CAP_REMOTE_WEB_URL = "https://pocket-ledger.com"
      npx cap sync android

3rd — Gradle: .\android\gradlew.bat assembleDebug  (sirf ek baar ya native change par)

Bundled/offline APK wapas: env hata kar `npm run cap:sync` + `npm run build:static` (default `capacitor.config` phir sirf `out` use karta hai)


===== Android APK (bundled out — offline / store jaisa) =====

1st — npm run build:static

2nd — npm run cap:sync               (ya sirf web bundle: npm run cap:copy:android)

3rd — android folder: .\gradlew.bat assembleDebug    (release ke liye assembleRelease)
