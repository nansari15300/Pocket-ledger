cd "D:\Static Build Project"


===== Dev (browser) =====
1st — npm install                    (sirf pehli baar / deps change ke baad)
2nd — npm run dev


===== Production Next (Node server, static/PWA bundle nahi) =====
1st — npm install
2nd — npm run build
3rd — npm run start


===== PWA / static website (Serwist + .\out\) =====
1st — npm install                    (zarurat ho tab)
2nd — npm run build:static           (.\out\ folder banega)
3rd — .\out\ deploy karo HTTPS par (Netlify/Cloudflare/VPS/waghaira) ya local test ke liye project root se: npx serve out  — browser root URL kholo.
      (Prod install / SW stable = HTTPS ya localhost; file:// avoid karo.)
(Optional agar tiers seed chaho build time — PLANS_SEED_URL / PLANS_SEED_FILE set karke dubara step 2.)


===== Android APK =====
1st — npm run build:static
2nd — npm run cap:sync               (ya sirf web bundle: npm run cap:copy:android)
3rd — android folder: .\gradlew.bat assembleDebug    (release ke liye assembleRelease)


===== iOS =====
1st — npm run build:static
2nd — npm run cap:copy:ios
3rd — Xcode se open karke Run / Archive


===== Desktop Windows (.exe) =====
1st — npm run build:static
2nd — npm run electron:build:win


===== Desktop Linux =====
1st — npm run build:static
2nd — npm run electron:build:linux


===== Sab ek baar me (static + cap android/ios copy + Electron win+linux) =====
1st — npm run build:static:all       (ye hi poore chain ko chalata hai — alag steps manually nahi)
